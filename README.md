# 🎓 Study with Subha

Study with Subha is a local AI-powered study assistant built with Streamlit and Ollama.

## Features

- 📚 Upload PDF, TXT and DOCX files
- 🔎 Search relevant information from uploaded notes
- 🤖 Ask questions using local AI
- 💬 Chat history
- 📝 Simple study explanations
- 🎯 Exam-friendly answers
- 🌐 English and Bengali questions
- 🔐 No OpenAI API key required

## Technologies

- Python
- Streamlit
- Ollama
- PyPDF2
- python-docx
- RAG
